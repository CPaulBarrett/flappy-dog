# Flappy Dog 3D

A small browser game: guide a voxel dog through the gaps between columns. Built with [three.js](https://threejs.org/) in a single HTML file.

## Play

**Play online:** https://cpaulbarrett.github.io/flappy-dog/

To run it locally, serve the folder and open it in a browser:

```
python3 -m http.server 8000
```

Then go to http://localhost:8000/. three.js loads from a CDN, so you need an internet connection.

## Controls

- **Space**, **Up arrow**, **click** or **tap**: flap
- The same keys restart after a game over

Your best score is saved in the browser.
